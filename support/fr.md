# MyMonth — Assistance

Questions, bugs ou idées : écrivez à [krasovskyi.yevhenii@gmail.com](mailto:krasovskyi.yevhenii@gmail.com). Nous répondons en général sous 2 jours ouvrés.

## Questions fréquentes

### Où sont stockées mes données ?

Uniquement sur votre appareil. MyMonth fonctionne sans compte ni connexion Internet.

### Comment transférer mes données vers un nouvel iPhone ?

Vos données font partie de la sauvegarde de l’iPhone. Restaurez une sauvegarde iCloud ou sur ordinateur (ou utilisez « Démarrage rapide ») sur le nouvel iPhone et elles suivront.

### MyMonth paie-t-il mes factures ?

Non. L’app suit seulement les paiements et vous les rappelle dans l’app ; aucun argent n’est transféré.

### Comment supprimer toutes mes données ?

Réglages → Données → Supprimer toutes les données, ou supprimez l’app.

### D’où viennent les taux de change ?

De [ExchangeRate-API](https://www.exchangerate-api.com), mis à jour une fois par jour. Les totaux convertis dans une autre devise sont approximatifs.
